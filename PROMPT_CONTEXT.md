# Контекст проекта: Real-time Web Jam Tool (Clean Room Implementation)
## 1. Стек технологий
- Frontend: HTML5, CSS3, Vanilla JS (ES6 Модули) с упором на Pointer Events для мобильных тач-экранов.
- Audio Engine: Открытая библиотека Tone.js (подключение через официальный CDN). Runs only on HOST.
- Real-time/Network: Открытая библиотека Socket.io для синхронизации без задержек.
- Target Devices: Мобильные браузеры (для Гостей-контроллеров), Десктоп/Планшет (для Хоста).

## 2. Структура файлов проекта
- /index.html — Главный интерфейс (Экран выбора: "Войти как Хост" или "Войти как Контроллер", UI тач-пада, сетка секвенсора).
- /style.css — Мобильный UI: темная тема, крупные touch-friendly элементы, запрет нативного скролла и зума.
- /src/audio/engine.js — Инициализация Tone.js на Хосте, управление аудио-контекстом по кнопке "Start Audio", темп (BPM).
- /src/audio/drums.js — Класс драм-машины на Хосте (сэмплы, 16-шаговая сетка-секвенсор, которую можно редактировать).
- /src/audio/synth.js — Полифонический синтезатор (PolySynth) на Хосте с логикой аккордов, тональностей и струма.
- /src/audio/effects.js — Независимые эффекты на Хосте: Delay, Reverb, Distortion, Reverse (буферный эффект), Wah-Wah (динамический фильтр). Эффекты можно настраивать отдельно для драм-машины и синтезатора.
- /src/ui/touch-pad.js — Оригинальная логика обработки координат X/Y с тач-панели (на устройствах Гостей) и отправка данных.
- /src/network/socket.js — Модуль сетевой синхронизации (отправка тачей от Гостей -> прием и озвучка на Хосте).

## 3. Техническое задание для модулей

### А. Динамический XY Touch Synth (synth.js & touch-pad.js)
1. Режимы игры: "Single Note" (одиночные ноты по оси X) и "Chords" (аккорды в выбранной тональности).
2. Настройки: Выбор тональности (Root Note) и музыкального лада (Major, Minor, Pentatonic). Точный математический расчет частот нот.
3. Эффект Strum (Струм): Воспроизведение нот аккорда с микро-задержкой (time-offset) для имитации удара по струнам.
4. Играемое на тач-панели должно легко поддаваться записи внутри сессии, удалению или наложению (игра поверх записанного слоя).

### Б. Цепочка Эффектов (effects.js)
1. Реализуй независимые модули эффектов (Delay, Reverb, Distortion, Reverse, Wah-Wah).
2. На Хосте должна быть возможность применять и крутить эти эффекты отдельно для драм-машины и отдельно для синтезатора.
3. Эффект Wah-Wah (фильтр) должен модулироваться в реальном времени движением пальца по оси Y на тач-паде.

### В. Мобильный UI и Правила
1. Интерфейс контроллера должен быть "No-Scroll / No-Zoom". Тач-панель "Dynamic XY Touch Synth" занимает максимум площади экрана.
2. Все переключатели (аккорды, тональности, эффекты) должны быть крупными touch-friendly кнопками или свайп-зонами для удобства на мобильном телефоне. Никаких мелких крутилок.
3. Весь код пишется с нуля на базе стандартов W3C и открытых лицензий MIT.
