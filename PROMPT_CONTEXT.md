# Контекст проекта: Real-time Web Jam Tool (Clean Room Implementation)

> Этот файл — снимок ТЕКУЩЕГО состояния кода. Если текст расходится с кодом — верен код; обнови этот файл в той же правке. Удалённое из кода удаляй и отсюда. Исключение — секция «Убрано — не возвращать» в конце.

Веб-инструмент для совместного музыкального творчества: телефоны гостей — XY-тач-контроллеры, весь звук считает одна машина-хост. Ниже — описание фактической архитектуры кода, а не пожелания.

## 1. Стек технологий
- Frontend: HTML5, CSS3, Vanilla JS (ES-модули), Pointer Events. Никаких фреймворков и сборщика.
- Audio Engine: Tone.js 15.0.4 (`https://cdn.jsdelivr.net/npm/tone@15.0.4/build/Tone.js`). Работает ТОЛЬКО на Хосте; на телефонах гостей аудио-код даже не импортируется (ленивые импорты в `src/main.js`).
- Real-time/Network: Socket.io 4.7.5 — клиент с CDN (`cdn.socket.io`), сервер `socket.io` в `server/server.js`.
- Server: Node.js 18+, Express 4 (`express.static` раздаёт корень), порт 43117 (env `PORT`), лимит подключений `MAX_CONNECTIONS` (по умолчанию 10) с экраном «Server is full» и авторетраем.
- QR: QRCode.js (davidshimjs) с jsDelivr, подгружается лениво.
- PWA: `manifest.json` + `sw.js` (service worker-заглушка, все запросы идут в сеть), кнопка «Install App to Home Screen».
- Деплой: локально/LAN — Socket.io на той же машине, что и страница; публичная сборка (GitHub Pages) ходит в бэкенд на Render: `PUBLIC_BACKEND_URL = https://web-jam-tool.onrender.com` (`src/network/socket.js`).
- Target Devices: мобильные браузеры (Гости-контроллеры), десктоп/планшет/телефон (Хост).

## 2. Структура файлов проекта
- `/index.html` — экран выбора роли + разметка экранов HOST и CONTROLLER (все шиты, сплэши, оверлей «Server is full»).
- `/style.css` — тёмная тема, крупные touch-элементы, no-zoom; на контроллере страница скроллится вертикально, тач-пад — нет.
- `/server/server.js` — Express + Socket.io: статика, `/api/lan` (LAN-IP для QR), сессии по 4-символьным кодам, роутинг тачей/контролов, гейт по числу подключений.
- `/src/main.js` — роутер ролей, ленивые импорты вью, `?role=host` / `?role=controller&code=XXXX`, регистрация SW.
- `/src/views/host.js` — сборка аудио-графа хоста и весь его UI: XY-пад с режимами Notes/FX (пять X-зон: левая — только фильтр без статтера, дальше Stutter 1/4–1/32; Y биполярный — выше середины high-pass, ниже low-pass, середина — байпас; отпускание гасит статтер и открывает фильтр; в FX-режиме весь `.play-bar` (Notes/Chords + Rec/undo) прячется ради места под пад, при басе прячется только селектор Notes/Chords — аккордов у баса нет), драм-шит, Notes-шит, Master-шит (8-bit/Wah/громкость), экспорт, приём тачей и контролов гостей, рассылка `host:state`/`host:pulse`.
- `/src/views/controller.js` — экран гостя: тач-пад, Notes/Chords, инструменты, Rec — на переднем плане; эффекты инструмента, «More» и кнопка мастер-эффектов (8-bit/Wah/громкость) спрятаны за шитом «Advanced». У пада тот же переключатель Notes/FX: FX-жесты летят на хост как `masterFx`/`masterHold` контролы по `controller:control`. Лад у гостя не выбирается — только отображается в шапке (задаёт хост). Зеркала драм-сетки и Notes-редактора (правки уходят контролами на хост).
- `/src/audio/engine.js` — Tone.js контекст, мастер-шина (`Gain → Compressor → masterFx → Limiter(-2)`; гейн — `state.masterFx.volume`, дефолт `DEFAULT_MASTER_GAIN` = 0.78, крутится слайдером в Master-шите), BPM, `lookAhead = 0.02`, duck/restore при уходе вкладки в фон. `start()` только по жесту «Start sound».
- `/src/audio/synth.js` — голоса инструментов, лады, аккорды, `resolveGesture` (единая функция «палец → ноты/лейбл» для хоста и гостя), `PerformanceRecorder` (лупы на `Tone.Transport`).
- `/src/audio/drums.js` — драм-машина: 7 дорожек, сэмплы TR-808 с jsDelivr + синтез-fallback, сетка 16/32/64 шага, триоли, пресеты, repeat, общий pitch ±12 полутонов (`setPitch`, `playbackRate = 2^(pitch/12)`, у синтез-голосов — shift частоты).
- `/src/audio/effects.js` — `createInstrumentBus` (по 3 эффекта на инструмент), `createDrumBus` (Dist/Cut/Room), `createMasterFx` (Stutter/биполярный Cutoff LP+HP/8-bit/Wah). Также лежит старая модульная библиотека `Effect`/`EffectChain` (Delay, Reverb, Distortion, Reverse-на-AudioWorklet, WahWah) — живой тракт её не использует.
- `/src/audio/export-loop.js` — экспорт лупа: MIDI (SMF, PPQ 480, барабаны на канале 10) и WAV через `Tone.Offline` (офлайн-рендер той же цепочки, включая master FX, громкость мастера и лимитер), repeats 1–128.
- `/src/ui/touch-pad.js` — Pointer Events → нормализованные `x,y ∈ [0,1]` (y снизу вверх), троттл 30 Гц + мин-дельта 0.002, мультитач, направление движения. `TouchPadRenderer` — канвас-свечение и сетка, отрисовка строго по событиям (нет холостого rAF). Под касанием подсвечивает активную колонку ступени и зоны аккордов (`zoneBounds`/`activeZone` через `setZones`/`setChordMode`); подсветку зон дублирует CSS-классами статичная разметка `#…-y-zones`. Третий режим рендера `'fx'`: пять вертикальных зон — левая «—» без срезов, затем 1/4→1/32 (линии уплотняются вправо); пунктирная средняя линия = фильтр открыт, выше неё оттенок светлеет (срез НЧ), ниже темнеет (срез ВЧ); активная зона под пальцем подсвечена с лейблом `деление · Гц LP/HP`.
- `/src/ui/piano-roll.js` — общий редактор нот (лента: время → вправо, высота → вверх), тап по пустой in-scale клетке ставит ноту, тап по ноте удаляет, драг двигает, правый край — длительность, режим select-and-move с марки, чужие ноты — пунктиром.
- `/src/ui/drum-grid.js` — общая сетка секвенсора (хост и гость): тап пишет/стирает, драг — прокрутка/кисть, зеркала repeat, столбец плейхеда.
- `/src/ui/quiet-touch.js` — `<button>` → `div[role=button]` (иначе iOS вибрирует на каждое нажатие), слайдеры с собственным pointer id.
- `/src/ui/scroll-edges.js` — метки «есть ещё контент» по краям скроллеров и страницы.
- `/src/ui/install-share.js` — кнопка установки PWA и QR с URL страницы на экране ролей.
- `/src/ui/icons.js` — SVG-иконки для кнопок.
- `/src/network/socket.js` — `JamSocket`: выбор backend (local/LAN vs Render), события, ack-запросы, volatile-move, гейт «Server is full».
- `/scripts/*.mjs` — стенды: `perf-probe.mjs` (CPU вкладок через CDP), `cpu-sampler.mjs`, `jam-scenario.mjs`, `verify-*.mjs`, `stuck-note-probe.mjs`, `transport-sync-probe.mjs`, `screenshot-ui.mjs`, `make-icons.mjs`, `env-check.mjs`, `harmony-check.mjs`, `balance/` (`sample-stats.mjs` — peak/RMS/онсет WAV-сэмплов; `snare-candidates.mjs` — сравнение вариантов снейра по яркости; `mix-probe.mjs` — офлайн-рендер каждого голоса соло и полного микса в headless Chrome).

## 3. Фактическая реализация модулей

### А. XY Touch Synth (synth.js, touch-pad.js)
- Пять инструментов: **Pad** (пул глайд-осцилляторов, fatsine), **Bass** (один моно-осциллятор, всегда одна нота, регистр на две октавы ниже; перекрытая нота возвращается после отпускания крышки), **Organ** (PolySynth sine4), **Kalimba** (FMSynth), **Synth** (глайд-пул, triangle). Алиас `piano` → `synth`.
- Режимы: `single` (одна нота по оси X) и `chords` (аккорд на ступени лада). У баса режим всегда single.
- Гармония: тональность (root, 12 нот), лады Major/Minor/Pentatonic, октава на инструмент (1–6). Расчёт частот — равномерная темперация `f = 440·2^((m−69)/12)`.
- В `chords` ось Y выбирает диатоническое расширение снизу вверх: triad → sus2 → sus4 → seventh → ninth; все тона остаются внутри лада. Лейбл аккорда (`Am7`, `Cmaj9`…) считает тот же `resolveGesture`, что и звук, — гость видит точное имя.
- Velocity зависит от Y и инструмента; аккорды пада приглушены относительно одиночных нот.
- Громкость голосов выровнена по держащемуся RMS на уровне 0.8 (`volume`: pad −6, bass −1, organ −9, kalimba 0, synth −6.5 dB); разброс ≤2 дБ на одиночной ноте, пад и бас чуть выше середины по требованию микса.
- Новый живой аккорд «рубит» (choke) аккорды того же инструмента других пальцев — без длинного release-хвоста.

### Б. Драм-машина (drums.js, drum-grid.js)
- Дорожки: Kick, Snare, Hi-Hat, Clap (основной банк) + Open Hat, Tom, Cowbell (extra).
- Сэмплы — набор Roland TR-808 (Michael Fischer, 1994, «ABSOLUTELY FREE») с `cdn.jsdelivr.net/gh/fluid-music/open-drums/tr-808/TR808WAV` (scoped npm-URL с `@` jsDelivr отвечает 400). Таймаут загрузки 4 с на голос: не грузится → остаётся синтез (Membrane/Noise/Metal), пилюля на хосте показывает источник. Clap подрезается до пика (`clapTrimStart`), чтобы бить в сетку; у остальных сэмплов атака уже на старте (<1 мс), подрезка не нужна. Пулы по 4 `Player` на голос.
- Баланс голосов проверен замером peak/RMS через `Tone.Offline` (`scripts/balance/`): `SAMPLE_GAIN` = kick 1 / snare 0.78 / clap 0.45 / tom 0.78 / hat 0.68 / openhat 0.5 / cowbell 0.62 — kick опорный, спред пиков ≈5 дБ. Снейр — `SD/SD2575.WAV` (мощное мид-лоу тело + snap-слой): `playbackRate` 0.87 опускает питч в регистр старого снейра, а общая для обоих путей цепочка lowshelf 550 Гц / −3 дБ + highshelf 3000 Гц / −3 дБ прибирает середину/низ и смягчает верх, не теряя яркости. Клэп — `CP.WAV` с `playbackRate` 1.15 и кэпом длительности 0.24 с (`SAMPLE_DURATION`) — ярче и с тугим хвостом вместо длинного реверба; плюс общий air-shelf 2200 Гц / +3.5 дБ на обоих путях. `volume` синтез-fallback подобран под уровень своего сэмпла (kick −4, snare −5, hat −13, clap −3, openhat −18, tom −6, cowbell −20 dB).
- Сетка: 16/32/64 шага (1/2/4 бара, по умолчанию 32 — два такта), `Tone.Sequence` на 16-е. Клетка циклится пусто → удар → триоль внутри этой доли → пусто.
- Пресеты: Four, Break, Offbeat, Jersey Club (32 шага), Empty — ряд крупных чипов прямо на главном экране хоста (`#host-drum-presets`) и в футере гостя (`#controller-drum-presets-main`), дублируются в драм-шитах; смена бита в один тап через `pickDrumPreset` / `pickGuestDrumPreset`. Текущий подсвечен `is-picked`; ручная правка сетки снимает подсветку (`state.drumPreset` → `''`, `markDrumPreset`/`paintGuestDrumPreset` красят оба ряда). Repeat Off/1/2 бара зеркалит первые бары на остальные.
- Редактирование: тап по клетке, драг-кисть по клеткам, режим записи Single/Triplet, зум слайдером. Сложное редактирование (repeat-зеркала, длина лупа, триплеты, pitch ±12) спрятано за галочку «Advanced» в драм-шите и у хоста, и у гостя; без неё остаются пресеты, тап-набор и зум. Pitch съезжает контролом `drumPitch` и живёт в `state.drums.pitch`.

### В. Эффекты (effects.js)
- У каждого инструмента своя шина с тремя эффектами (уровень Off/Low/High чипами + «More» — слайдеры деталей): Pad — Reverb/Delay/Chorus; Bass — Distortion/Cutoff(лопас)/Slap; Organ — Chorus/Vibrato/Room; Kalimba — Delay/Reverb/Reverse; Synth — Room/Delay/Chorus. У драм-машины отдельная шина Distortion/Cutoff/Room. На выходе шин всех инструментов, кроме баса, стоит highshelf 2200 Гц / −8 дБ — держит верх инструментов ниже полосы крэка снейра (~1.5–3 кГц).
- Reverse у калимбы — захват хвоста на `ScriptProcessor` и проигрыш буфера задом наперёд (AudioWorklet на `http://` в LAN недоступен, поэтому его нет в живом тракте).
- Компенсация громкости: wet-ветки уменьшают dry по таблице `WET_RETAIN`, а makeup-gain возвращает уровень. Cutoff на 0 — настоящий байпас.
- Мастер-эффекты (после микса, до лимитера): **Stutter** (удерживаемый срез 1/4–1/32 через FeedbackDelay на полном уровне), **Cutoff** — биполярная пара общего тракта: lowpass 14000→180 Гц ниже середины Y и highpass 24→4000 Гц выше неё, взаимоисключающиеся, оба на 0 — настоящий байпас, короткий рамп против зипперинга; **8-bit** (WaveShaper-квантизатор, без лифта), **Wah** (бандпас 160→2400 Гц с лифтом ×4.8). Stutter и Cutoff живут на главном экране: чипы Notes/FX переключают пад — в FX-режиме X делит пад на `FX_PAD_DIVISIONS` (первая зона — только фильтр без статтера, остальные держат статтер на своём делении), Y — биполярный фильтр с мёртвой зоной по центру, отпускание гасит статтер и открывает фильтр. Мастер-шит: 8-bit, Wah и громкость мастера (`engine.setMasterVolume`, гость шлёт `masterFx.volume`); Wah живёт только в шите — при рассылке `host:state` инпут, за который сейчас держатся, не перезатирается.
- У каждого голоса, включая барабаны, флаги Mute/Solo.

### Г. Лупы и редактор Notes (synth.js PerformanceRecorder, piano-roll.js)
- Луп пишет только ноты (on/up), квантованные к сетке 16-х `Tone.Transport` через `scheduleRepeat` — привязан к драм-машине без setTimeout. Эффекты в буфер не пишутся: записанный луп слышен через текущие ручки. `on` без парного `up` (тейк ещё держат или off потерян) в `#perform` не звучит вовсе — иначе нота висла бы весь цикл; при закрытии тейка звучащие `loop:`-голоса глушатся сразу.
- Длина лупа: 2 → 4 → 1 бара кнопкой «N bars». Аккорд сохраняется группой степеней лада; слайд пальцем режет полосу на сегменты по питчам.
- Лупы общие: хост рассылает `loopNotes` всех игроков в `host:state`, редактор Notes у всех показывает одну партию. Чужие ноты — пунктиром, но редактируются так же: правки гостя идут контролами `eraseNote`/`moveNote`/`moveGroup`/`addNote` на хост, хост находит владельца по `voiceId` и пишет в его рекордер.
- История: Undo/Undo all/Redo, `clr all` и `clr curr inst` (очистка только текущего инструмента во всех лупах), Rec/stop у каждого игрока. Рядом с `clr all` в плей-баре сидят стрелки ⟲/⟳ — откат/накат только СВОИХ правок (`ownPast` по ownerId, включая записанный тейк и очистку своих лупов); `clr all` показывает только иконку корзины и после очистки временно становится кнопкой отмены до следующего витка бара.
- Транспорт: Play/Stop, BPM-пресеты 80/96/120/140 (клэмп 40–200). Хост шлёт volatile `host:pulse` с номером шага — у гостей ползет плейхед, номер бара и биты-точки.

### Д. Экспорт (export-loop.js)
- `MIDI` — SMF-файл лупа ×N повторов: ноты всех инструментов по каналам, барабаны на канале 10 (GM-ноты).
- `WAV` — офлайн-рендер (`tone.Offline`, 44.1 кГц, стерео) той же цепочки: инструменты и барабаны → master → compressor → masterFx → limiter. Учитываются mute/solo, уровни и master FX.
- Repeats: целое 1–128.

### Е. Сеть и сессии (server.js, socket.js)
- События: `host:create` → 4-символьный код (алфавит без похожих букв), `controller:join` (код + имя), `controller:touch` (move летит volatile), `controller:control` (все настройки гостя: инструмент, эффекты, октава, луп, барабаны — включая `drumLength`/`drumPitch`, BPM, транспорт, мастер-FX, правки нот, `history` undo/redo, превью высоты), `host:state` (мерж-рассылка тональности, готовности, лупов, барабанов, masterFx), `host:pulse`, `peer:join`/`peer:leave`, `session:closed`.
- QR на хосте открывает `http://<lan-ip>:43117/?role=controller&code=XXXX` — код руками не вводится; для localhost хост подставляет LAN-IP из `/api/lan`.
- Отключение хоста закрывает сессию для всех; уход гостя глушит его голоса (`releaseMatching` по префиксу peerId).

### Ж. Мобильный UI и правила
- Тач-пад: `touch-action: none`, запрет `contextmenu`/`selectstart`/двойного зума, `gesturestart` preventDefault. Пад хоста и гостя занимает максимум площади.
- Все переключатели — крупные chip-кнопки; слайдеры только в детальных шитах и для зума. Никаких мелких крутилок.
- На живых экранах `<button>` заменяются на `div[role=button]` — иначе iOS вибрирует при каждом тапе (`quiet-touch.js`).
- Правила производительности, которые стережёт стенд: перерисовка только по событиям, тачи в сеть ≤30 Гц и только при реальном сдвиге, аудио-узлы создаются один раз при старте — на касание идут только триггеры и установка параметров.
- Весь код инструмента написан с нуля на стандартах W3C под MIT. Исключение — сэмплы TR-808: бесплатный набор «без ограничений», но это не MIT (см. README § «Барабаны»).

## Запуск
```bash
npm install
npm run dev   # http://127.0.0.1:43117
```
Хост: `/?role=host` → «Start sound». Гость: QR или `/?role=controller&code=XXXX`. Публичная версия — статика на GitHub Pages + Socket.io на Render.

## Убрано — не возвращать
- AudioWorklet-reverse в живом тракте — недоступен на `http://` в LAN; живой reverse у калимбы на `ScriptProcessor` (`createTailReverse`).

- Инструмент «piano» переименован в «synth»; алиас остался только в `normalizeInstrument` для совместимости со старыми лупами.
- Wah-Wah, модулируемый осью Y тач-пада гостя — в живом тракте такой связи нет; мастер-wah крутится слайдером.
